Altair GitHub App

Creates the GitHub App your Altair server needs, with every address, permission and event filled in.

1. Create the app on GitHub

GitHub asks you to confirm, creates the app and sends you to your Altair address with ?code=… in the address bar. Copy that code.

2. Get the keys

The app was created. These keys are shown only now.

Add each one in Cloudflare as a secret: Workers & Pages → altair → Settings → Variables and Secrets → Add, type Secret. Then redeploy.
