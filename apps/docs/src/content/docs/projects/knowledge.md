Every task in the project works from three things: instructions and memory, in the **Memory and instructions** tab (the brain icon), and files, in the **Files** tab.

## Instructions

Rules every task in the project follows, such as the tone to write in, the branch to use or who to check with before something is published.

1. Open **Memory and instructions** → **Instructions**.
2. Write your rules in plain words.
3. Choose **Save instructions**.

## Memory

Notes Myrel keeps across tasks, so you don't explain the same thing twice: decisions you made, how you like things done, facts about the project. Myrel writes and updates these itself; you can read and edit them.

- **MEMORY** is the short index every task reads first.
- Choose **New** to add a note yourself, with a name, a one-line description and the content.
- Each note shows who last wrote it and when. Myrel sees those dates too, so it knows how old a note is.

### Notes that may be out of date

When Myrel finds a note that no longer matches the project and can't tell what is right, it doesn't delete it. It marks it **May be stale** with the reason, and the note gets a yellow strip.

- Choose **Still true** if the note is right after all.
- Choose **Delete** if it no longer applies.
- To fix it, open the note, change it and choose **Save**.

Myrel only deletes a note you agreed to remove. When a note changes, its previous version is kept: open the note and expand **Previous version** to see it, or choose **Bring this version back** and **Save** to undo the change.

### Memory upkeep

Notes go out of date as the project moves on. With **Memory upkeep**, Myrel checks them against the project now and then: once a number of threads have finished, and at most once a week, it opens a **Memory upkeep** thread. There it fixes notes that are plainly out of date, marks the ones it can't confirm, and asks you before deleting any.

At the top of the memory list, owners and admins pick how it runs:

- **Automatic**: on when tasks run on a CLI on your computer, off when they run in the cloud, so it never uses your plan by itself.
- **On**: always, including in the cloud.
- **Off**: never on its own.

**Check now** starts a check right away.

## Files

The **Files** tab holds everything uploaded to the project, and the files Myrel creates for you.

- **Upload** adds files here directly.
- Files you attach to a message are saved here too, under `uploads/`.
- When Myrel creates a report or a document for you, it puts it here and links it in the thread.
