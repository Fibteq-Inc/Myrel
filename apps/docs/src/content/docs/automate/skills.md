A skill is a set of instructions (and optionally scripts and references) for a particular kind of work: your release checklist, your brand's writing style, how to prepare a client report. Myrel reads it when a task calls for it.

## Your skills and project skills

- **Settings** → **Skills** (**Your skills**): skills you can use in any of your projects.
- **Project settings** → **Skills**: skills for one project, shared with its members. Your own skills are turned on per project here too.

## Add a skill

| Option | When to use it |
|---|---|
| **From GitHub** | The skill is in a public repository. Paste `owner/repo`, a folder link or a skills.sh link |
| **Write one** | Write the name, a description and the instructions here |
| **Upload a folder** | You have the skill as a folder on your computer |

**Find skills on skills.sh** opens a catalog of public skills. For a skill from GitHub, **Update from GitHub** pulls its latest version.
