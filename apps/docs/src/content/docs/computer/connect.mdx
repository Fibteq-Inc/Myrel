Tasks can run on your own computer instead of the cloud. They work in folders you choose, with the coding CLI you already use and pay for (Claude Code, Codex CLI, Antigravity CLI, OpenCode, Hermes Agent, Cursor CLI, Muse Code or Kimi Code). Your CLI's login never leaves your computer, and these tasks don't count toward your plan's limits.

The bridge between Myrel and your computer is a small program called **myrel-runner**.

## Before you start

- Node.js 22 or newer
- At least one supported CLI installed and signed in. See [Choose a coding CLI](/computer/clis/).

:::tip[Desktop app]
The desktop app has myrel-runner built in. Open **Devices** → **This computer** → **Connect this computer** and skip the terminal steps below.
:::

## Check it works

Ask for something small in the project, like "list the files in this folder". Under the reply you should see **Your computer** and the name of your CLI.
