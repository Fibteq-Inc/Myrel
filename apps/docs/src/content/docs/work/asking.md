Everything starts in the project's **Conversation**. Type into **Give Myrel a task** and send it with Enter (Shift + Enter adds a new line).

Myrel answers under your message and opens a thread for the task. A follow-up about work that is already running goes to that thread instead of starting a new one.

![A project chat: each ask gets a short reply and a thread card](../../../assets/screenshots/project-chat.png)

## Write a good ask

Write it as you would to a capable colleague who just joined:

- **Say the outcome.** "Find out why the signup page is slow on mobile and suggest fixes" works better than "look at signup".
- **Give the context you know.** Links, the file or page it is about, what you already tried.
- **Say how you want it back.** A short answer, a report, a pull request, a draft to review.
- **Name the limits.** "Don't change the API", "keep it under a page", "ask me before emailing anyone".

You don't need to split work into steps. Myrel makes its own plan and shows it in the thread.

## Attach files

Choose the paperclip (**Attach files**), paste, or drag files onto the message. You can attach up to 10 files of up to 25 MB each. They are saved in the project's files under `uploads/`, so later tasks can use them too.

Very long pasted text becomes a text file attachment automatically; choose **Insert as text** to put it back into the message.

## Choose the CLI for an ask

When the project works in a folder on [your computer](/computer/connect/), the composer shows which coding CLI the task will use. See [Choose a coding CLI](/computer/clis/).

## Several asks at once

Send as many asks as you like. Each gets its own thread and they run side by side. The **Threads** tab lists them all with their status.
