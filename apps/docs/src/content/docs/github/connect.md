---
title: Connect repositories
description: Give a project access to your GitHub repositories.
---

Connect a repository and Myrel can clone it, work on a branch and open pull requests. It uses the Myrel GitHub App, so you choose exactly which repositories it can see.

## Connect

1. Open **Project settings** → **GitHub**.
2. Choose **Connect GitHub**.
3. On GitHub, install the Myrel app on your account or organization and pick its repositories.
4. Back in Myrel, choose **Add repository** and add the ones this project should use.

Already installed the app for another project? Choose **Already installed? Sign in with GitHub** instead.

## Change access

- **Add an account or repositories** changes which accounts and repositories the app can see.
- **Refresh from GitHub** picks up changes you made on GitHub.
- **Disconnect** removes a repository from this project.

:::note[Self-hosted servers]
On your own Myrel server, an admin sets up a GitHub App first. Until then the page says "GitHub is not set up on this server yet". See the [self-hosting guide](https://github.com/Fibteq-Inc/myrel/blob/main/docs/self-hosting.md#github-app).
:::
